Este arquivo é apenas o modelo do formato. Para espelhar uma edição do Substack:

1. Duplicar este arquivo com um nome descritivo (vira a URL: `/insights/nome-do-arquivo`).
2. Preencher `title`, `description`, `pubDate` e `substackUrl` da edição.
3. Colar o texto em Markdown abaixo do frontmatter.
4. Trocar `draft: true` por `draft: false` para publicar.
